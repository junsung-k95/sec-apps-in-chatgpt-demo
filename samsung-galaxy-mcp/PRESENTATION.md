# Samsung Galaxy Services — ChatGPT 연동 MCP 서버 소개

---

## 슬라이드 1: 프로젝트 개요

### ChatGPT 안에서 삼성 Galaxy 서비스를 바로 이용할 수 있다면?

이 프로젝트는 ChatGPT 대화 안에서 삼성전자의 Galaxy 서비스 3가지를 **대화형으로 안내하고, 실시간 위젯(화면)으로 정보를 보여주는** 시스템입니다.

**지원 서비스:**
- **Samsung Care+** — 기기 보험 가입 상담 (사진으로 기기 상태 확인까지)
- **New 갤럭시 AI 구독클럽** — 구독형 기기 업그레이드 프로그램 안내 및 비용 비교
- **보상판매 (Trade-in)** — 기존 기기의 예상 보상가 조회 및 정밀 견적

**동작 방식:**
사용자가 ChatGPT에 질문하면 → ChatGPT가 MCP 서버의 도구(기능)를 호출해 정보를 가져오고 → 결과를 텍스트 + 인터랙티브 위젯으로 보여줍니다.

## 슬라이드 6: 핵심 기술 포인트 — AI Vision 활용

3개 시나리오 중 2개에서 **ChatGPT의 Vision(이미지 분석) 기능**을 활용합니다.

### Care+ Late Enrollment
- 사용자가 기기 사진 업로드 → ChatGPT가 화면/외관/카메라 상태 분석 → 서버에 결과 전달 → 가입 승인/거절 판정

### Trade-in 정밀 견적
- 사용자가 기기 사진 업로드 → ChatGPT가 상태 분석 → 서버에 결과 전달 → 기존 자가진단 견적 대비 재산정 (보통 상향 조정)

**포인트:** 사진 분석 자체는 ChatGPT가 수행하고, MCP 서버는 그 결과를 기반으로 **비즈니스 로직** (가격 계산, 적격성 판정)을 처리합니다.

## 슬라이드 9: 요약

### 이 프로젝트가 보여주는 것

1. **ChatGPT 안에서 삼성 서비스를 자연어로 이용** — 별도 앱 설치 없이, 대화만으로 Care+ 가입, 구독 비교, 보상판매 견적까지
2. **AI Vision을 활용한 기기 상태 자동 판정** — 사진만 올리면 화면/외관/카메라 상태를 분석하여 가격 산정 또는 가입 승인
3. **인터랙티브 위젯** — 텍스트 답변만이 아니라, 비교표/차트/버튼이 있는 화면을 ChatGPT 대화 안에서 직접 표시
4. **MCP 표준 프로토콜** — ChatGPT뿐 아니라 MCP를 지원하는 다른 AI 어시스턴트에도 동일한 서버를 연결 가능
